
# 语文试卷一键排版工具 V8（启动注意页面）

这个版本已改为 `python-docx` 实现，不再依赖 Windows 桌面版 Microsoft Word。当前版本只支持 `.docx` 文件；老式 `.doc` 文件请先用 Word 或 WPS 另存为 `.docx`。


## V2：批量文件队列与顺序对应

新版会先按照文件名称自动排列，再把结果显示在文件队列表格中。表格第一列的 `001、002、003……` 是最终处理顺序；用户可以继续使用“上移”和“下移”进行图形化调整。

可以使用：

- “添加 Word 文件”一次选择多个文件；
- “添加整个文件夹”批量载入；
- “按文件名重新排序”重新识别阿拉伯数字和汉字数字序号；
- “上移”和“下移”手工调整；
- “删除选中”和“清空”修改队列；
- 双击文件或在下方输入框中修改该文件对应的题头名称。


### 汉字数字排序

程序识别常见汉字数字：

```text
一、二、三……十、十一、十二、二十、一百
第一、第二、第三
第一课、第二单元、第十二天
```

例如下面的文件会按 `一、二、三、十、十一` 排列，而不是按普通字符顺序排列：

```text
一_基础练习.docx
二_字词训练.docx
第三课_古诗文.docx
十_阅读训练.docx
十一_作文训练.docx
```


### 文件名前序号的处理

文件名开头的数字只参与排序和卷号生成，不会直接进入题头。

例如：

```text
001_第一天.docx      → 顺序 1，题头名称“第一天”
二、古诗文练习.docx   → 顺序 2，题头名称“古诗文练习”
第三课 阅读专项.docx  → 顺序 3，题头名称“阅读专项”
十一_作文训练.docx    → 顺序 11，题头名称“作文训练”
```

因此不会出现题头显示成“001_第一天”的问题。

默认还会按照队列表格顺序自动生成卷号：

```text
第一个文件 → 01卷
第二个文件 → 02卷
第三个文件 → 03卷
```

关闭“按文件队列顺序自动生成卷号”后，所有文件使用界面里手工填写的固定卷号。


## V3.1 按钮显示修复

“开始批量处理”现在有两个入口：

1. 文件队列右上角；
2. 参数区下方的操作栏右侧。

## V4 重点修改

### 1. 修复题头继承正文有序列表

原文第一段是自动编号列表时，Word 可能把新插入的三行题头也编号为 `1、2、3`，正文则变成 `4`。V4 会在插入后强制清除题头段落的列表格式，使题头保持无编号，正文原有编号继续保留。

### 2. 文件名不再作为题头

文件名只用于：

- 自动判断处理顺序；
- 在文件队列表格中显示；
- 生成输出文件名。

文件名中的文字和开头序号都不会进入题头。

### 3. 题头可按队列顺序自动编号

在任意题头输入框中加入：

```text
[序号]
```

默认位数为 1 时，将依次生成：

```text
1、2、3……10
```

使用：

```text
[序号:3]
```

将依次生成：

```text
001、002、003……100
```

还可以设置起始值和步长。例如起始值 5、步长 2，会生成 `5、7、9……`。

典型设置：

```text
作业/试卷名称：暑假作业第[序号]天
卷号：[序号:2]
使用日期：2026年7月[序号]日
```

批量序号严格按照图形界面中的最终文件顺序计算。使用“上移”或“下移”后，编号也会随之变化。

### 4. 窗口尺寸

默认窗口恢复为约 `980 × 780`，最小尺寸约 `860 × 650`，避免界面过大。


## V5：使用 `{}` 在指定位置插入批量序号

在题头的任意输入框中写：

```text
{}
```

程序会把每个 `{}` 替换成当前文件的批量序号。可以放在文字前、中间或后面，也可以在一个输入框中使用多次。

示例：

```text
作业/试卷名称：第{}次暑假作业
卷号：{}
使用日期：2026年7月{}日
```

### 只输入首位数

用户只需要填写“首位数”，程序自动识别编号形式并逐个加 1。

| 首位数 | 输出 |
|---|---|
| `1` | `1、2、3……` |
| `01` | `01、02、03……` |
| `001` | `001、002、003……` |
| `一` | `一、二、三……` |
| `十` | `十、十一、十二……` |
| `九十九` | `九十九、一百、一百零一……` |

阿拉伯数字会自动保留首位数的位数。例如输入 `001`，后续编号自动补足三位。

汉字数字会继续用汉字输出。

首位数中包含字母、标点、混合字符或其他格式时，程序会提示：

```text
只支持阿拉伯数字（如 1、001）或汉字数字（如 一、十一）。
```

文件名仍然只参与自动排序，不进入题头。编号按照图形界面中经过上移、下移后的最终顺序生成。


## V6：多组独立编号

可以通过“添加编号”建立多组互不干扰的编号：

```text
{编号1}
{编号2}
{编号3}
……
```

每一组都有自己的首位数，并分别按最终文件队列顺序加 1。

例如设置：

```text
编号1首位数：一
编号2首位数：001
编号3首位数：10
```

题头填写：

```text
作业名称：第{编号1}天练习
卷号：{编号2}
使用批次：第{编号3}批
```

依次生成：

```text
第一个文件：第一天练习，卷号001，第10批
第二个文件：第二天练习，卷号002，第11批
第三个文件：第三天练习，卷号003，第12批
```

可以在同一个输入框中同时使用多个编号：

```text
第{编号1}单元第{编号2}份
```

`{}` 继续兼容旧版本，等同于 `{编号1}`。

每组首位数只接受：

- 阿拉伯数字：`1`、`01`、`001`、`15`
- 汉字数字：`一`、`十`、`十一`、`一百零一`

其他格式会明确指出是哪一组编号不合法。


## V7 修改内容

### 文件夹选择窗口缩放修复

程序会在创建窗口之前启用 Windows DPI 感知，并在打开、关闭文件夹选择窗口时保存和恢复窗口尺寸与 Tk 缩放比例。用于修复在系统选择窗口中点击“新建文件夹”后，主界面突然变大的问题。

默认主窗口仍保持约 `980 × 780`。

### 编号占位符简写

新版使用：

```text
{1}
{2}
{3}
```

例如：

```text
作业名称：第{1}天练习
卷号：{2}
使用日期：2026年7月{3}日
```

旧写法 `{编号1}` 仍兼容。

### 关于页面

程序左上角有一个“关于”入口。内容直接写在 `word_exam_formatter.py` 顶部：

```python
ABOUT_TITLE = "..."
ABOUT_VERSION = "..."
ABOUT_AUTHOR = "..."
ABOUT_TEXT = """..."""
```

修改这些变量即可更改关于页面。

### 一键打包 EXE

双击：

```text
一键打包EXE.bat
```

脚本会自动安装依赖和 PyInstaller，并生成：

```text
dist\语文试卷一键排版.exe
```

当前 python-docx 版不需要 Microsoft Word；目标电脑只需能运行本程序，并处理 .docx 文件。


## V8：启动注意页面

启动程序后不再弹出注意窗口。点击“开始批量处理”时，当天首次会弹出“使用前注意”窗口；点击确认后才开始排版。

注意页面内容直接写在 `word_exam_formatter.py` 顶部：

```python
NOTICE_TITLE = "使用前注意"
NOTICE_TEXT = """
这里填写注意事项内容
"""
```

修改后重新运行程序即可生效，无需修改界面代码。


## 配置方案保存位置

填充配置方案会自动保存到程序当前目录下的：

```text
填充配置方案\*.json
```

主配置文件保存在程序当前目录：

```text
word_exam_formatter_config.json
```

如果从旧版本升级，程序会尝试把用户目录里的旧配置复制到当前目录。
## 已实现功能

- 单个 Word 文件或整个文件夹批量处理；
- 支持 `.docx`；`.doc` 会提示先另存为 `.docx`；
- 在全文最前面插入题头；
- 将正文中的 `[[题头]]` 批量替换成完整题头；
- 设置题头三行：
  - 学校、学年学期、作业名称；（第一行加粗三号）
  - 年级学科及卷号；
  - 出题人、审题人、使用日期；
- A4 纸；
- 上下左右页边距；
- 保留横向页面；
- 正文字体、字号和 1.5 倍行距；
- 自动识别并加粗大题标题；
- 页脚显示“语文 第 X 页 共 Y 页”；
- 批量另存为 `.docx`；
- 默认不覆盖原文件；
- 保存常用排版预设；
- 自动保存多个 JSON 填充配置方案，并可在界面中一键切换。

## EXE 版本说明

`dist` 目录中保留两个可执行文件：

```text
语文试卷一键排版.exe              # Win10 / Win11 推荐
语文试卷一键排版_Win7兼容版.exe   # Win7 / Win10 / Win11 通用兼容版
```

如果 Windows 7 启动时报 `api-ms-win-core-path-l1-1-0.dll` 缺失，请使用 `Win7兼容版`。该版本使用 Python 3.8.10 32-bit 和 PyInstaller 4.10 打包。

## 环境要求

- Windows 7、Windows 10 或 Windows 11；
- Python 3.8 或更高版本；
- 不需要安装 Microsoft Word。

## 安装

在命令提示符中进入本程序目录，运行：

```bat
pip install -r requirements.txt
```

## 启动

双击：

```text
启动工具.bat
```

也可以运行：

```bat
python word_exam_formatter.py
```

## 假期作业中重复插入题头

在每一份作业开始的位置单独输入一行：

```text
[[题头]]
```

例如：

```text
[[题头]]
一、选择题……

[[题头]]
一、现代文阅读……
```

选择“start_and_markers”时，程序既在全文开头添加一次题头，也替换所有标记。

选择“markers”时，只替换标记，不在全文开头额外添加。

## 推荐参数

根据提供的要求，默认值已设置为：

- A4；
- 上边距 2.3 cm；
- 下边距 2.3 cm；
- 左边距 2.1 cm；
- 右边距 2.1 cm；
- 正文宋体小四，即 12 磅；
- 题头宋体三号附近，即 16 磅、加粗；
- 页脚宋体小五，即 9 磅；
- 正文 1.5 倍行距。

字体字号在不同学校的具体规定中可能略有差异，界面里可以直接修改。

## 打包成 EXE

安装 PyInstaller：

```bat
pip install pyinstaller
```

运行：

```bat
pyinstaller --noconsole --onefile --name 语文试卷一键排版 word_exam_formatter.py
```

生成的 EXE 位于：

```text
dist\语文试卷一键排版.exe
```

注意：当前 python-docx 版不需要 Microsoft Word，但只支持 .docx。

## 使用注意

1. 第一次使用时先拿副本测试，不要直接勾选“覆盖原文件”。
2. 正在 Word 中打开的文件可能无法保存，请先关闭。
3. 自动识别大题标题依赖正则表达式，特殊标题可在“高级选项”中修改。
4. 页边距按 Word 的“节”逐节设置。
5. 原文中的横向页面默认保留。
6. 复杂文档处理后应人工检查一次分页、公式和图片位置。
